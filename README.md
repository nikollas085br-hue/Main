# Central de Estudos — M5Stack Cardputer ADV

Projeto PlatformIO para ESP32-S3/M5Cardputer.

## Build

```bash
pio run -e m5stack-cardputer
```

O projeto deliberadamente não possui pasta `data/`: os conteúdos do cartão SD ficam no pacote separado.

## Recursos
- interface horizontal por cartões;
- matemática científica, equações, exponenciais, funções e gráfico;
- física com assistente de suposição de cálculo;
- tabela periódica de 118 elementos e análise de ligações;
- navegador do SD e leitor de textos;
- anotações no SD;
- ponto de acesso Wi-Fi `Cardputer-Estudos` para upload em `/ANOTACOES`.
